关于本站

👋 你好！

欢迎来到 wqnlll 游戏中心！这是一个由个人独立开发维护的免费在线小游戏网站。

我们的初衷很简单：用有趣的方式帮助小朋友学习英语，同时提供一些经典的休闲小游戏，让大家在忙碌之余放松一下。

🎯 我们的游戏

目前收录了以下游戏：

  • 英语打砖块 —— 将小学英语单词融入经典打砖块玩法。每个砖块都是一张单词卡（英文 + 中文），打碎时自动朗读发音。覆盖 8 大主题 200+ 核心词汇，让背单词不再枯燥。适合小学生和英语初学者。
  • 坦克大战（电脑版） —— 经典俯视角射击游戏，WASD 移动 + 空格开火，保护基地、消灭敌军。致敬红白机时代的经典之作。
  • 坦克大战（手机版） —— 为手机触屏专门优化的版本，虚拟摇杆操控，随时随地来一局。核心玩法与电脑版一致，操作方式更适合移动端。

💡 为什么做这个网站

作为一个开发者，我一直觉得学习编程最好的方式就是动手做项目。这些游戏是我在学习和实践中一步步打磨出来的。把它们免费分享出来，既是对自己技能的检验，也希望能给其他人带来一些乐趣和帮助。

特别是英语打砖块这个游戏，灵感来自于看到小朋友背单词很痛苦——与其死记硬背，不如在游戏中自然习得。每打碎一块砖，就记住一个单词，这种即时反馈让学习变得轻松愉快。

🛠 技术栈

本网站所有游戏均使用原生 HTML5 + CSS + JavaScript 开发，不依赖任何前端框架。游戏画布基于 HTML5 Canvas API 渲染，音效使用 Web Audio API / Speech Synthesis API。托管在 GitHub Pages 上，通过 HTTPS 提供安全访问。
